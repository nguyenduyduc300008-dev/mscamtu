NHÀ CUNG CẤP AI

Kết nối API để giao việc

Chọn nhà cung cấp, tạo API key bằng tài khoản của bạn, rồi lưu key ở Supabase. Key không được nhập vào trang web hoặc lưu trên GitHub.

Google Gemini · có thể dùng miễn phí

Google AI Studio có mức miễn phí giới hạn theo model, khu vực và quota hiện hành. Không gửi dữ liệu nhạy cảm khi dùng mức miễn phí.

Tạo Gemini API key ↗ GEMINI_API_KEY Xem giá và giới hạn ↗

OpenAI API · tính phí riêng

OpenAI API là dịch vụ tính phí theo mức sử dụng và thường không nằm trong gói ChatGPT. Kiểm tra giá và billing trước khi tạo key.

Tạo OpenAI API key ↗ OPENAI_API_KEY Xem giá API ↗
  1. Mở Supabase Secrets, thêm secret của nhà cung cấp bạn chọn và dán API key vào đó.
  2. Quay lại giao việc, chọn đúng nhà cung cấp. Không cần thêm key vào GitHub Pages.
Mở Supabase Edge Function Secrets ↗

Quota miễn phí có thể thay đổi hoặc hết. Mỗi API key do bạn tự quản lý; không gửi key qua chat hay cho người khác.
